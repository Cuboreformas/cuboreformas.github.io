# CUBO Reformas — Landing v1

Landing one-page preparada para captar solicitudes desde Meta Ads.

## Archivos
- index.html
- style.css
- script.js
- images/

## Antes de publicar
1. En `script.js`, cambia `TU_NUMERO_DE_WHATSAPP` por el número real, con prefijo internacional y sin `+` ni espacios.
2. En `script.js`, cambia `TU_URL_DE_INSTAGRAM` por el perfil real.
3. Sustituye:
   - `images/hero.svg`
   - `images/cocina.svg`
   - `images/bano.svg`
   - `images/salon.svg`
   por fotografías reales de CUBO Reformas.
4. Añade las páginas legales reales antes de publicar.

## Formulario
El formulario está preparado para abrir un correo dirigido a:
info.cuboreformas@gmail.com

Más adelante se puede conectar a un servicio de formularios gratuito para recibir los leads directamente sin depender del programa de correo del visitante.

## Publicación gratuita
Una opción sencilla es GitHub Pages. Sube estos archivos a un repositorio y activa Pages.
